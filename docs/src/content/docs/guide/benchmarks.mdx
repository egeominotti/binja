## Latest audit run

Recorded 2026-07-23 on macOS arm64, Apple M1 Max, 32 GiB RAM, Bun 1.3.14. Each result is the median of 15 warmed rounds; setup and compilation are outside the timed region.

|---|:---:|---:|---:|---:|---:|
| Lexer / default delimiters (2.3K chars) | sync | 207,164 | 188,383–218,412 | 4.5% | 48.27 ms |
| Lexer / custom delimiters (2.3K chars) | sync | 209,161 | 196,276–212,770 | 2.6% | 47.81 ms |
| Runtime / simple cached AST | async | 2,420,551 | 1,443,419–2,554,591 | 11.4% | 8.26 ms |

The relatively high RSD for the simple runtime and AOT cases is disclosed rather than hidden; use more rounds and controlled system load for performance decisions.

## What the harness guarantees

Before timing, it verifies:

- runtime and AOT output equality for the simple and loop templates;
- default/custom-delimiter lexer equivalence;
- expected Liquid offset/limit/reversed output;
- expected `rejectattr` result size and predicate.

The harness then warms each case, separates synchronous and asynchronous loops, consumes every result, and reports every sample through JSON mode.

## Run it

```sh
bun install
bun run benchmark

# Longer, machine-readable run
BENCH_ROUNDS=15 bun run benchmark -- --json
```

`BENCH_ROUNDS` must be an integer of at least 3; invalid values fall back to 7.

## Interpreting results

These cases are microbenchmarks, not HTTP throughput or latency tests. Do not compare their ops/s across different workloads. In particular, a simple AOT function and an asynchronous loader-backed render solve different problems.

For a useful before/after comparison:

1. use the same checkout dependencies, Bun version, machine, power mode, and round count;
2. close background workloads;
3. compare identical cases and inspect RSD plus min/max, not only the median;
4. retain correctness tests alongside any optimization;
5. benchmark the real application template and context shape before making deployment claims.

Historical competitor ratios were removed because the repository did not retain a current, equivalent cross-engine harness that could reproduce them.
