## What binja provides

<CardGrid>
  <Card title="Runtime + AOT" icon="lightning">
    Use loader-backed asynchronous rendering or compile the supported static subset to a synchronous function.
  </Card>
  <Card title="Safe defaults" icon="seti:lock">
    Autoescape, root-contained loaders, protected property access, HTML-safe JSON, and explicit trust boundaries.
  </Card>
  <Card title="Multi-engine subsets" icon="puzzle">
    Documented compatibility subsets for Handlebars, Liquid, and Twig, exposed through stable package subpaths.
  </Card>
  <Card title="91 filter entries" icon="setting">
    String, collection, mapping, date, encoding, and Django/Jinja-style filters plus 35 test entries. Counts include aliases.
  </Card>
</CardGrid>

## Install

```sh
bun add binja
```

Binja requires Bun 1.3.14 or newer.

## Choose an API

<Tabs>
  <TabItem label="Runtime string">
    ```ts
    import { render } from 'binja'

    const html = await render('Hello, {{ name|upper }}!', { name: 'world' })
    ```
  </TabItem>
  <TabItem label="AOT function">
    ```ts
    import { compile } from 'binja'

    const renderHeading = compile('<h1>{{ title }}</h1>')
    const html = renderHeading({ title: 'Welcome' })
    ```
  </TabItem>
  <TabItem label="File environment">
    ```ts
    import { Environment } from 'binja'

    const env = new Environment({ templates: './views', cache: true })
    const html = await env.render('pages/home.html', { title: 'Home' })
    ```
  </TabItem>
</Tabs>

## Measured locally

The 2026-07-23 audit run used Bun 1.3.14 on an Apple M1 Max with 15 warmed rounds. The current harness reported 2,420,551 ops/s for a simple cached runtime AST and 10,008,841 ops/s for the equivalent simple AOT function. These are local microbenchmarks, not cross-engine claims or deployment guarantees.

[Read the methodology and complete results →](/binja/guide/benchmarks/)

## Compatibility scope

The core is a broad, tested Jinja/Django-compatible subset. It is not a complete implementation of Python Jinja2 or Django Templates. The Handlebars, Liquid, and Twig modules are likewise explicit subsets and do not expose every upstream helper, tag, loader, or host-framework integration.
